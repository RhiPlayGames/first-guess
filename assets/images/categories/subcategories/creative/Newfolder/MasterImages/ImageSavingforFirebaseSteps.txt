Every time you want to process a new folder
Open Photoshop.
Go to:
File → Automate → Batch…
Under Play, check:
Set: First Guess Firebase Images
Action: 512x512 WebP
Under Source:
Select Folder
Click Choose…
Navigate to the folder containing the images you want to resize.
You will not see the individual images in this window — that's normal.
Click Select Folder.
Under Destination:
Select Folder
Click Choose…
Select the EXACT SAME FOLDER you chose for Source.
Click Select Folder.
Check:
☑ Override Action "Save As" Commands

Under File Naming, leave:

Document Name
extension

This keeps the existing filenames.

Leave these unchecked unless there's a specific reason to change them:
Override Action "Open" Commands
Include All Subfolders
Suppress File Open Options Dialogs
Suppress Color Profile Warnings
Errors: leave as Stop for Errors.
Double-check that Source and Destination show the same folder.
Click OK.
Photoshop will process every image in that folder using:
512 × 512 px → WebP → Lossy Quality 75
Because your originals are backed up, allow Photoshop to replace/overwrite the existing files if prompted.
